01. 数据采集方法（Real-World Collection）

遥操作示教（Teleoperation）

适合快速收集高质量动作-视觉配对轨迹，常用于行为克隆（BC）和离线策略初始化。

在岗日志采集（Fleet Logging）

从真实部署系统持续回流失败与恢复样本，提升策略稳健性与恢复能力。

多模态同步采集

统一时间戳对齐 RGB / 深度 / 关节状态 / 力矩 / 语言指令，避免训练时的跨模态漂移。

方法 适用阶段 关键风险 参考来源
跨机构真实数据协作 基座策略预训练 异构机器人/标注口径不一致 Open X-Embodiment (arXiv:2310.08864)
统一硬件采集协议 中规模数据持续扩展 采集成本与设备维护 DROID Dataset
视觉-语言-动作联合数据 高层任务泛化 语言指令与动作对齐误差 RT-2 (arXiv:2307.15818)

02. 数据合成方法（Synthetic Data）

合成数据目标不是“替代真实数据”，而是补齐真实场景的长尾覆盖：罕见光照、异常碰撞、复杂障碍与极端视角。

  • 域随机化：对纹理、材质、光照、动力学参数做系统扰动，以提升 Sim2Real 泛化。[Tobin et al.]
  • 程序化场景生成：批量生成可控任务组合，用于构造失败样本与恢复样本。
  • 自动标注流水线：在仿真中自动导出接触状态、位姿、关节信息，降低人工标注成本。
🧠 AntiGravity's Commentary

合成数据真正值钱的不是数量，而是“失败模式覆盖率”。如果你的合成管线没有刻意制造干扰与反例，训练出来的策略在真实环境中通常会过度乐观。

官方工具入口： Isaac Sim Docs， Isaac Lab， ManiSkill Docs， Omniverse Replicator。

04. 强化学习进展（RL Progress）

DreamerV3：统一配置的世界模型 RL 基线

🟢 通俗解读

先在“想象中的环境”里大量试错，再把学到的策略迁回真实任务，减少昂贵的真实交互。

🔴 专业解读

通过 latent dynamics 学习环境转移并进行 imagined rollouts，核心价值是样本效率和统一训练配置。

🧠 Commentary

适合作为“世界模型 + 控制策略”评估起点，但落地时需补齐真实机器人安全约束与延迟预算。

Diffusion Policy：高维动作生成策略

在机器人操作任务中，扩散式策略对多峰动作分布更稳健，尤其适合抓取、装配等存在多解的任务。

来源定位：Abstract / Method / Robot manipulation experiments。

Cosmos Policy：视频世界模型到机器人策略

将 action / future state / value 编码为统一序列并单阶段微调视频模型，在 LIBERO、RoboCasa、真实场景中报告了可复现评测结果。

来源定位：Abstract / §3 Method / §4 Experiments。
