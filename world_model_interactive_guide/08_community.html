09. 社区动态与讨论追踪 (Community)

社区内容用于捕捉前沿信号，但不直接等同事实。关键结论必须回到论文、代码和官方文档验证。

9.1 热点议题

💬 议题 A：VLA 是否会统一“感知-规划-控制”栈？

社区高频观点：VLA 可以显著减少模块拼接复杂度，但在线稳定性与安全控制仍需传统控制器兜底。

讨论入口： X Search: OpenVLA robotics | Reddit Search: OpenVLA | OpenVLA Project

🧠 Commentary：社区共识正在形成：VLA 是主干，但“安全层 + 低层控制”短期内不会消失。

💬 议题 B：具身数据规模扩张的瓶颈在哪里？

高频争论点：真实数据昂贵、异构平台口径不统一、失败样本稀缺。

讨论入口： X Search: Open X-Embodiment | Open X-Embodiment Paper | DROID Dataset

🧠 Commentary：下一阶段竞争点不是“数据总量”，而是“跨平台对齐 + 失败恢复样本密度”。

💬 议题 C：仿真是否足够替代真实数据？

主流观点：仿真是放大器，不是替代品；Sim2Real 回流机制才是关键。

讨论入口： X Search: Isaac Lab Sim2Real | Isaac Lab Docs | ManiSkill Docs

🧠 Commentary：没有“实机失败回流”的仿真体系，最终会沦为离线演示工具。
