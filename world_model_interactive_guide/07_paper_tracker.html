07. 具身智能论文追踪 (Papers)

按“可复现价值”优先收录论文：不仅看指标，还看数据可得性、代码开源和部署意义。

⏰ 最后更新时间: 2026-02-14 | 本页内容将每日更新「具身智能 VLA / 数据 / RL / 仿真相关论文」。

2026-01

Cosmos Policy: Diffusion World Model Policy Learning

📅 2026-01-27 📄 arXiv:2601.16163 NEW

🟢 通俗解读：把“看见什么、接下来怎么做、值不值得做”统一进一个模型里，减少模块拼接损耗。

🔴 专业解读：将 action / future state / value 作为统一序列进行建模，在 LIBERO、RoboCasa、真实任务上报告性能。来源定位：Abstract / §3 Method / §4 Experiments。

🧠 Commentary：这条路线价值在于系统简化，但部署时仍要处理在线安全约束与时延抖动。

2023

RT-2: Vision-Language-Action Models Transfer Web Knowledge

📅 2023-07-28 📄 arXiv:2307.15818

🟢 通俗解读：让机器人不仅会“看图做动作”，还会利用语言知识理解更抽象指令。

🔴 专业解读：将 vision-language 模型能力迁移到机器人动作 token 输出，提升跨语义泛化能力。来源定位：Abstract / §4 Experiments。

🧠 Commentary：RT-2 的价值是“语义泛化”，但工业落地仍需补充可验证的安全层与恢复策略。

Open X-Embodiment: Robotic Learning Datasets and RT-X Models

📅 2023-10-13 📄 arXiv:2310.08864

🟢 通俗解读：多个机构把机器人数据“对齐后汇总”，用于训练更通用的策略模型。

🔴 专业解读：跨数据源聚合与统一训练协议是其关键贡献，缓解单机构数据分布窄的问题。来源定位：Abstract / Dataset & Training sections。

🧠 Commentary：它证明了“数据合作”对泛化的重要性，但标准化成本与协议治理同样关键。

Diffusion Policy: Visuomotor Policy Learning via Action Diffusion

📅 2023-03-07 📄 arXiv:2303.04137

🟢 通俗解读：像生成图片一样逐步生成动作序列，动作更稳定、抖动更少。

🔴 专业解读：扩散模型刻画多峰动作分布，在操作任务中提升稳健性。来源定位：Abstract / Robot manipulation experiments。

🧠 Commentary：非常适合复杂操作任务，但线上推理成本需与控制频率一起评估。
